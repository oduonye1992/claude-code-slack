# Hashtag Strategy

## By Platform

### TikTok

Use 5–8 hashtags per post. Mix high-volume with niche.

**High volume (100M+ views):**
```
#mentalhealth #anxiety #selfcare #wellness #mindfulness
```

**Mid tier (10M–100M views):**
```
#mentalhealthawareness #anxietytips #burnout #selfcaretips #mentalwellness
#anxietyrelief #stressrelief #mentalhealthmatters
```

**Niche / community (1M–10M views):**
```
#anxietywarrior #burntout #sundayscaries #workanxiety #quietquitting
#therapyhumor #mentalhealthcheck #adultinganxiety #highfunctioninganxiety
```

**Aurie-specific:**
```
#Aurie #AurieApp #talktosomeone #mentalhealthapp
```

**Trend-specific tags:** Add 1–2 tags tied to the specific trending topic.

## Hashtag Rules

1. **Never use crisis hashtags** — `#suicide`, `#selfharm`, `#cutting` — these are monitored and
   can restrict distribution. See `knowledge/clinical/compliance.md`.

2. **Rotate, don't repeat** — Using the same hashtag block every post signals spam to algorithms.
   Build 3–4 hashtag sets and rotate them.

3. **Check trend relevance** — Add 1–2 trending hashtags only when they're genuinely relevant.
   Forced trend-jacking damages credibility.

4. **Platform-specific sets** — Never copy-paste the same hashtag block across platforms.

---

## Monthly Review

Review hashtag performance monthly. Retire tags that consistently underperform. Add rising
community tags as Aurie's audience grows.
