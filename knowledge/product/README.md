# Aurie — Product Overview

## What Aurie Is

Aurie is an AI mental health companion designed to feel like a trusted friend — not a therapist,
not a clinical tool, not a chatbot. It is voice-first, available 24/7, and built for people who
want emotional support between (or instead of) formal therapy sessions.

## Core Value Proposition

**"Support that fits your life — not a waiting room."**

- Instant access, no appointment needed
- Voice-first — talk naturally, not type into a form
- Judgment-free — every response is warm, never dismissive
- AI-powered — learns your patterns over time
- Complementary to therapy — never a replacement

## Key Features

| Feature | Description |
|---|---|
| Daily check-ins | 3-minute guided emotional temperature-taking |
| Voice journaling | Speak, not type — Aurie listens and reflects |
| Mood tracking | Visual patterns over time, no charts to fill in |
| Breathing exercises | Simple, contextual — not one-size-fits-all |
| Crisis support | Immediate 988 / crisis line referral when needed |
| Personality memory | Aurie remembers what matters to you |

## Positioning

Aurie sits between:
- **Meditation apps** (Calm, Headspace) — too passive, not interactive
- **Therapy** — too expensive, too slow to access
- **Self-help** — too much work, too easy to drop

Aurie is active support, always available, zero barrier to entry.

## Key Differentiators vs. Competitors

- **Voice-first** (competitors are text-heavy)
- **Personality memory** (feels like talking to someone who knows you)
- **Warm AI, not clinical AI** (Woebot / Wysa feel like CBT worksheets)
- **Real-time emotional intelligence** (not scripted response trees)

## App Store

Available on iOS and Android. Free tier with daily check-in. Premium for unlimited sessions.
